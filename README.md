# 🧠 Flutter Web Object Detection App (TensorFlow.js)

This is a Flutter Web application that allows users to upload an image and detect objects within it using a pre-trained [COCO-SSD model](https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd) from TensorFlow.js. The entire detection works **offline** in the browser, with no backend or cloud API.

## ✨ Features

- Upload an image directly from your device.
- Run object detection using TensorFlow.js and COCO-SSD.
- Display predictions (labels + confidence scores) in the Flutter UI.
- Browser-based: Runs fully in the browser.
