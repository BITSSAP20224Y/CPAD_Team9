# Plant Disease Classification App

**Plant Disease Classification** is a Flutter application that utilizes Teachable Machine and TensorFlow Lite to classify plant diseases from captured images with high accuracy. This app features a clean and intuitive interface, allowing users to diagnose plant diseases in real-time using their device's camera.
